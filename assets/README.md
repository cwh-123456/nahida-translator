# assets

程序会从这里读取**看板娘 / 翻译面板背景动图**：

```
assets/nahida_swing.gif
```

## 说明

- 仓库**不包含**任何游戏素材或同人图。想启用动态背景，请自行准备一张 GIF（建议 1:1、≤ 10MB），
  命名为 `nahida_swing.gif` 放进本目录即可，无需改代码。
- 如果这个文件不存在，程序会正常启动，只是没有看板娘和动态背景（其余功能不受影响）。
- 图片版权归原作者 / 米哈游所有，请仅本地个人使用，不要二次分发。

## 快捷方式图标（可选）

给 `start.bat` 建快捷方式后，可以在「属性 → 更改图标」里选本目录的 `nahida.ico`。

**这个 ico 必须包含多档尺寸**，否则桌面上会显示成空白方块或很糊：

```
16 24 32 48 64 128 256
```

Windows 桌面图标有四档（小 / 中 / 大 / 超大），分别取 16、48、96、256 像素；
缺哪一档就由系统拿最接近的那张硬放大，缺得太多（比如只有 48）时会直接画不出来。
Windows 资源管理器本身跑在 100%~250% 缩放下，所以 64 / 128 / 256 都要有。

自己做一个：拿一张 ≥ 256×256 的方图，用 `ImageMagick`：

```
magick icon.png -define icon:auto-resize=256,128,64,48,32,24,16 nahida.ico
```

改完图标后桌面没变，是 Explorer 的图标缓存（`%LOCALAPPDATA%\Microsoft\Windows\Explorer\iconcache_*.db`）：
按 `F5`、把快捷方式重命名一次，或重新在「更改图标」里确认一遍即可刷新。
注意 `.bat` 文件本身的图标是 shell 固定的，**只有快捷方式的图标能改**。
